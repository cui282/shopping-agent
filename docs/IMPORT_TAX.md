# 中国大陆进口税费实现边界

本模块只计算目的地为中国大陆的到手成本。它不是报关系统，也不维护一张静态税率表。商品数据
提供商必须按商品、HS Code、原产地、进口模式和计算日期返回税率证据；Shopping Agent 校验字段、
按确定性公式复算并向客户披露来源。税率变动通过数据快照更新，不通过修改平台常量更新。

## 为什么不能按平台计税

适用关税税率由商品归类、原产地、协定或优惠安排、暂定税率及可能的贸易救济措施共同决定，平台
名称和发货国不能替代这些要素。当前税率应以海关税率查询和当年关税调整方案为准：

- [中华人民共和国关税法](https://gss.mof.gov.cn/gzdt/zhengcefabu/202404/t20240426_3933677.htm)
- [2026 年关税调整方案](https://gss.mof.gov.cn/gzdt/zhengcefabu/202512/t20251229_3980625.htm)
- [海关进出口税率查询](https://online.customs.gov.cn/ociswebserver/pages/jckspsl/index.html)

因此 live offer 缺少 `customs` 证据时，系统返回 `tax_exclusions`，而不是使用 Amazon、Shopee、
AliExpress 或 eBay 的默认比例。

## 支持的进口模式

### 一般贸易

数据提供商返回适用的关税税率种类、关税率、进口增值税率、消费税率，以及可审计的
`customs.valuation`。完税价格使用交易价格 CIF 口径；外币商品必须在估价证据中返回申报日期、
对应计税月份和海关计税汇率。该汇率独立于客户横向比较的 `price_conversion` 和最终支付汇率。
系统先校验各组成金额到分，再按以下口径复算：

```text
完税价格 = 商品价 + 国际运费 + 保险费
关税 = 完税价格 × 适用关税率
消费税 = (完税价格 + 关税) / (1 - 消费税率) × 消费税率
进口增值税 = (完税价格 + 关税 + 消费税) × 增值税率
```

海关还可能适用反倾销、反补贴或其他措施。当前本地公式不猜测这些项目；供应商应把已核定的复杂
场景作为 `seller_collected` 报价返回，或在后续契约中增加明确的特殊税费组件。

海关计税汇率按申报月份适用海关规定口径。数据通道必须返回当月已核验的 rate、provider 和
source reference；Shopping Agent 不从实时行情接口自行选一个汇率，也不把研究阶段的比价报价
当成申报汇率。规则边界可参考：

- [中华人民共和国海关进出口货物征税管理办法](https://www.mct.gov.cn/preview/whhlyqyzcxxfw/ss/202411/t20241106_956082.html)

### 跨境电商零售进口

只有数据提供商明确确认清单、交易和额度资格时，才能返回
`cross_border_ecommerce_eligible=true`。系统据此将关税税率设为 0，并按法定进口增值税、消费税
应纳税额的 70% 计算；交易价格口径包含商品零售价、运费和保险费。政策依据：

- [跨境电子商务零售进口税收政策](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5203746/content.html)
- [提高跨境电商零售进口限值](https://www.chinatax.gov.cn/chinatax/n810341/n810765/n3359382/201812/c4182338/content.html)

系统不持有消费者年度额度，也不从商品名称推断正面清单资格；资格必须由交易侧数据通道确认。

### 个人邮递物品

该模式不能只提供一个综合税率。数据提供商还必须明确确认个人合理自用资格、寄递物品订单总值、
海关核定计税价格、当前寄递限值、应征税额免税门槛，以及超过限值时是否为不可分割单件。系统
使用海关核定计税价格乘以综合税率；计算出的应征税额不超过数据快照中的门槛时，按快照免税并
披露减免前税额和减免原因。

现行办法自 2024 年 12 月 1 日起规定：寄递物品总值原则上不超过 2000 元，超过时只有经海关审核
确属个人合理自用的不可分割单件可继续按进境物品处理；应征税额不超过 50 元免税。上述限值仍由
数据通道作为带生效日期的政策证据返回，代码不从平台或商品标题猜测资格。系统也不内置不完整的
品类税率表，不把跨境电商零售进口规则套用到个人邮包。相关政策边界可参考：

- [进境物品关税、增值税、消费税征收办法](https://gss.mof.gov.cn/gzdt/zhengcefabu/202411/t20241129_3948540.htm)
- [海关进出境邮件常见问题](https://online.customs.gov.cn/ociswebserver/pages/jcjybcx/question.html)

### 卖家已代收

数据提供商可以返回结算页或卖家的进口税费合计报价。系统使用该合计值计算到手价，但不会虚构
关税、进口增值税和消费税的拆分。报价仍必须带 HS Code、原产地、来源引用和生效日期。

## 金额与展示

- `duty_cny` 只表示关税组件，可以为 `null`。
- `import_tax_cny` 表示用于到手价的进口税费合计。
- `landed_cny = price_cny + shipping_cny + insurance_cny + import_tax_cny`。
- `tax_breakdown` 保存归类、原产地、模式、税率、税种金额、来源和生效日期。
- `tax_breakdown.customs_valuation` 保存 CIF 组成、申报月计税汇率及来源引用；一般贸易和跨境电商
  缺少该证据时使用 `missing_customs_valuation` 排除，不回退到客户比较汇率。
- 客户界面和 PDF/Markdown 报告展示进口税费合计与必要证据；JSON 保留完整机器可读链路。

上线前应由报关、税务或数据供应商确认具体商品归类和税率。海关最终核定与平台结算页金额优先于
本项目的研究时点估算。
